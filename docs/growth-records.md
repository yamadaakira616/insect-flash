# ログインボーナスと成長記録

更新日：2026-09-29。公開版にも成長記録と算盤の足あとを追加。

## 追加した機能

- ログインした日に1回100コインを受け取り。通算7日ごとに300コインです。連続ログインでなくても進みます。同日の再読み込みや連打では重複しません。
- 「ログインした日数」と「練習した日数」を分けて集計。1〜100の算盤は途中までの記録も練習日数に含め、同日に何回練習しても日数は1日です。
- ホームから「せいちょうノート」を開くと、累計日数・回数・クリアしたレベル数を確認できます。
- 月ごとのカレンダーにログイン・練習・クリアを表示。日付を押すと、その日のレベル、モード、正解数、結果、算盤の到達数が分かります。
- 「できた日のアルバム」で各レベルの初クリア日と最近の達成日を保存。通常練習と検定チャレンジを分け、再クリアしても初回日は上書きしません。
- 「れんしゅうの足あと」に失敗した挑戦も含めて記録。日付・レベル・桁数・口数・秒数・正解数を残し、全記録の正答率も表示します。
- 結果画面からも成長記録へ移動できます。

## 以前の記録と保存

既存のコイン、シール、スクイーズ、星、練習回数は引き継ぎます。以前の版で保存されていなかったプレイ日や初クリア日は復元できないため、初クリア日を「日付不明」とし、日数は日付が分かる範囲だけ集計します。

記録は使用中のブラウザー内に保存します。「記録を保存（JSON）」は保管用ファイルの書き出しです。別端末への自動同期やファイル読み込みは今回追加していません。保存失敗時には画面に案内を表示します。

検定チャレンジの達成はアプリ内の練習記録です。正式な検定の合格認定ではありません。

## 確認結果

- 自動テストと製品用ビルドで保存・移行・算盤の記録を確認。
- ボーナスの重複防止、通算7日目・14日目、日付切替、初回達成日の保持、旧記録の移行、保存失敗時の案内を検証。
- 画面テストで日別履歴・検定と通常の切替・過去の日付不明表示を確認。
