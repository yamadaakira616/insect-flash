# 1〜100の算盤とお部屋アイテム

更新日：2026-09-29。公開先： https://yamadaakira616.github.io/insect-flash/

## 学習ルール

- じっくり練習：1から100まで順番に足す。各問題は「それまでの合計＋次の数」。答えが違えば同じ問題を再挑戦できる。途中でやめる際は記録するか破棄するか選べる。
- 1分チャレンジ：3秒の準備後、実物の算盤で1から順番に足す。60秒経過後に最後に足した数と合計を入力し、`n(n+1)/2` で照合する。途中終了時も確認ダイアログを経て答えを入力できる。
- 時間は絶対時刻で管理し、再読み込み後も同じ残り時間で再開する。画面を離れたら音を停止する。BGMは初期設定オフで、効果音と終了チャイムは個別に切り替えられる。
- 算盤の結果はシールや通常レベルと別に保存。完走した場合は従来の1日目・3回目の練習スタンプにも算入する。

## 背景のないお部屋アイテム

オリジナルの透過WebP画像16枚を `public/assets/room-items/` に収録。シールと別の所持一覧として記録し、最大6個をお部屋に飾れる。

| 学習 | 到達数とアイテム |
|---|---|
| じっくり練習 | 1 ほしのクッション／5 もこもこぐも／10 そろばんのぬいぐるみ／20 うさぎ／30 ねこ／40 おつきさまクッション／50 くま／60 あひる／70 きつね／80 ペンギン／90 パンダ／100 こじか |
| 1分チャレンジ | 正答かつ60秒完走で10 お花／30 きのこ／60 いちご |
| フラッシュ暗算 | 通算3回プレイでちょうちょ |

一度獲得したアイテムは再挑戦や再読み込みで消えず、同じ挑戦結果で二重配布しない。従来のプレイ回数から獲得したものは獲得日を「不明」として扱う。

## 保存の引き継ぎ

公開済みの `sticker-book-v2` にあるコイン、シール、スクイーズ、星、59レベルの進行、シール配置を保持する。古い `sticker-book-v1` の配置も10ページ形式へ移す。算盤の中断状態は別キー `insect-flash-abacus-session-v1` に保存し、結果の確定後は学習履歴へ記録する。記録は使用中のブラウザー内に保存され、別端末への自動同期はない。
